# StackLift Lab
Desarrollada por Juan Manuel Castaño Quiroz

Aplicacion full-stack para gestionar entrenamientos.

## Estructura

- `server`: API Node.js, Express, PostgreSQL y Prisma.
- `client`: interfaz React, Vite, TypeScript, Tailwind CSS y shadcn/ui.

## Inicio rapido

```bash
cd server
npm install
npx prisma generate
npm run dev
```

En otra terminal:

```bash
cd client
npm install
npm run dev
```
